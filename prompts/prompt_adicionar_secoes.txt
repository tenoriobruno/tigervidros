Adicione ao site existente uma seção de “Trabalhos Realizados” (portfólio) para a TigerVidros.

Objetivo:
Exibir serviços já feitos para gerar confiança e aumentar conversão.

Requisitos:

1. Estrutura
- Criar uma nova seção no index.html com id "portfolio"
- Título: "Trabalhos Realizados"
- Subtítulo curto opcional (ex: "Veja alguns dos nossos serviços")

2. Conteúdo
- Exibir uma grade (grid) de imagens
- Cada item deve conter:
  - imagem
  - pequena descrição (ex: "Box de banheiro", "Espelho sob medida")

3. Dados
- Os itens do portfólio devem ser definidos no script.js como um array de objetos
- Renderizar os itens dinamicamente via JavaScript

4. Layout e estilo
- Grid responsivo (mínimo 2 colunas no mobile, mais em telas maiores)
- Seguir a identidade visual existente:
  - fundo escuro (#0F1115)
  - tons de azul (#1C2F7A, #2F5FBF, #4FA3E3)
- Cards simples, com leve borda ou efeito sutil
- Hover com leve destaque

5. Boas práticas
- Código simples e organizado
- Não usar frameworks
- Não alterar outras seções do site
- Reutilizar classes existentes se possível

6. Opcional (se simples)
- Ao clicar na imagem, ampliar (lightbox simples)

Importante:
- Não reestruturar o site inteiro
- Fazer apenas o necessário para adicionar essa seção
