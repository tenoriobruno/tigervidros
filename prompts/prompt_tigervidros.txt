CONTEXTO DO PROJETO:
Site institucional de uma página para a vidraçaria TigerVidros.
Empresa pequena, início de operação. Usuário com pouca experiência em frontend.
Objetivo principal: gerar contatos via WhatsApp e direcionar para redes sociais.

ARQUIVOS A CRIAR:
- index.html
- css/style.css
- js/main.js

═══════════════════════════════════════════
REGRAS INEGOCIÁVEIS
═══════════════════════════════════════════

Aplicar antes de escrever qualquer linha:

- HTML, CSS e JS puro. Zero frameworks, zero CDN, zero bibliotecas externas
- Sem Google Fonts. Usar: system-ui, -apple-system, sans-serif
- Zero valores hardcoded de cor, espaço ou fonte no CSS — tudo via variáveis
- Sem !important, sem IDs no CSS, sem seletores com mais de 2 níveis
- Nenhuma função duplicada entre arquivos
- JS com no máximo 60 linhas totais
- index.html sem <style> inline
- main.js sem element.style (sem CSS inline via JS)
- Se uma solução tem mais de 20 linhas, existe uma versão de 10 — use ela
- Links externos: sempre target="_blank" rel="noopener noreferrer"
- Imagens: sempre atributo alt preenchido
- Placeholders editáveis marcados com comentário: <!-- EDITAR -->

═══════════════════════════════════════════
ARQUITETURA JS
═══════════════════════════════════════════

main.js — estrutura obrigatória, nesta ordem:

1. Scroll suave para âncoras do nav
2. Header: adicionar/remover classe .scrolled ao passar 80px
3. Menu hambúrguer: toggle de classe .open no nav (mobile)
4. Nada mais. Sem eventos desnecessários, sem variáveis globais

Mobile nav:
- Botão hambúrguer visível apenas em mobile (display: none em desktop)
- Ao clicar: nav-links recebe classe .open → display: flex, flex-direction: column
- Fechar ao clicar em qualquer link do menu
