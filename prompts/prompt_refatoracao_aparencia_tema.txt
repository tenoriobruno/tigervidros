### 3. Futuristic Smart Glass / SaaS Style

## 📱 UI/UX REQUIREMENTS

- Fully responsive (mobile-first)
- Clear visual hierarchy (hero → services → portfolio → testimonials → CTA)
- High readability (no over-light text on white)
- Strong CTA buttons:
  - “Solicitar orçamento”
  - “Falar no WhatsApp”
- Use real section structure, not just UI mock
- Avoid empty whitespace without meaning (no “blank feel”)
- Use real-world copy (not lorem ipsum)

---

## 🧱 STRUCTURE REQUIRED

Build the page with:

1. Hero section (impact + value proposition)
2. Services section (cards)
3. Portfolio / projects gallery
4. Why choose us (trust section)
5. Testimonials
6. Contact / CTA section (WhatsApp focused)

---

## ⚙️ DESIGN SYSTEM RULES

- Typography: modern sans-serif (Inter, system UI or equivalent)
- Spacing: generous but structured
- Colors:
  - Primary: neutral + slight blue/gray tint
  - Background: light only (no dark theme)
- UI style: premium architectural / glass aesthetic
- Cards: soft border + blur (if theme 1 is used)

---

## 🚫 DO NOT

- Do NOT use dark theme
- Do NOT create empty or low-density layouts
- Do NOT use overly flashy neon UI
- Do NOT reduce contrast to the point of illegibility
- Do NOT create generic “startup template look”
